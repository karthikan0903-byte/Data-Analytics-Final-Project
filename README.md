# Superstore Sales Data Analytics Final Project

## Project Overview
An end-to-end Exploratory Data Analysis (EDA) on the Superstore Sales dataset using Python in Google Colab. The project covers data loading, pre-processing, statistical summaries, pivot tables, 10 detailed visualizations, and business insights.

## Project Structure
- `superstore.csv`: Raw Superstore Sales dataset (9,994 rows).
- `Data_Analytics_Final_Project.ipynb`: Complete Python code with EDA and markdown documentation.

## Key Insights
1. **Technology Dominance:** Technology category generates the highest revenue and profit.
2. **Discount Threshold:** Discounts above 20% lead to steep net profit losses.
3. **Regional Performance:** West and East regions contribute to over 60% of total sales.
4. **Product Strategy:** Sub-categories like Tables and Bookcases frequently suffer operational losses.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Google Colab
